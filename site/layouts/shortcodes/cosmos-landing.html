Organize your windows into spaces.

Cosmos is a window and space manager for macOS. Assign windows to logical spaces, keep a different space visible on each display, and switch or move windows with keyboard shortcuts.

Read the documentation Installation

Spaces for windows

Group individual windows into logical spaces and switch between them as needed.

Multiple displays

Keep a different space visible on each display and move windows between displays.

Keyboard shortcuts

Switch spaces, move the focused window, or open a switcher without reaching for the mouse.

Switcher previews

Window and space switchers show cached previews, with app icons as a permission fallback.

Settings and YAML

Configure spaces and shortcuts in Settings or edit the YAML file directly.

Window recovery

Emergency unhide restores managed windows when a hidden window needs to be recovered.
